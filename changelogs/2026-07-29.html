Claude Code CLI

Key Highlights

  • Headless streaming — subagent nesting — Nested subagents now forward messages at every depth via parent_tool_use_id; new mcp_server_errors field in system/init exposes skipped MCP config entries for CI gating (requires v2.1.219).
  • Dev containers — auth persistence — Volume mount guidance updated to also set CLAUDE_CODE_DIR so ~/.claude.json (OAuth, MCP servers, project trust) persists across rebuilds alongside ~/.claude.
  • Hooks — PermissionRequest semantics — Event now fires for background subagents that cannot show a prompt; if no hook returns a decision the call is auto-denied. SessionEnd hooks gain a shared 1.5-second budget.
  • MCP — Microsoft Foundry tool-search behavior — Azure-hosted Foundry deployments always fall back to upfront MCP tool loading; ENABLE_TOOL_SEARCH=true cannot override the server-side rejection.
  • Settings — switchModelsOnFlag — New setting controls whether Claude Code auto-switches to the fallback model on a safety-classifier flag or pauses for user confirmation.
  • Network config — verify guidance — New section documents how to confirm proxy, CA cert, and mTLS settings loaded correctly via --debug and /status before sending any requests.
