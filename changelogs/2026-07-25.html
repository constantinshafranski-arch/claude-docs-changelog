Key Highlights

  • claude-opus-5 model added — New model claude-opus-5 introduced as "Powerful intelligence for long-running agents and coding"; added as a selectable option across all Agents, Sessions, Deployments, and Messages API endpoints.
  • AnthropicBeta enum expanded — Two new beta header values added across all endpoints: server-side-fallback-2026-07-01 and fallback-credit-2026-07-01, extending the fallback and credit beta feature versions.
  • Beta headers example models updated — Code examples in the Beta Headers doc updated to reference claude-opus-5 instead of claude-opus-4-8 across all SDK languages (cURL, CLI, Python, TypeScript, C#, Go, Java).
  • Session events ordering clarified — The created_at filter and sort parameters for List Events and List Session Thread Events endpoints now explicitly compare against the event's processed_at field, with returned data ordered by processed_at.
  • Mid-conversation tool control — The Beta Messages (Create, Count Tokens, Batches) endpoints now accept BetaRequestToolAdditionBlock and BetaRequestToolRemovalBlock within system message content blocks, enabling dynamic tool surfacing mid-conversation.
  • Model description updates — Older claude-opus model entries (4-5, 4-6, 4-7, 4-8) had their descriptions changed from varied strings (e.g., "Frontier intelligence", "Most intelligent model", "Premium model") to a uniform "Powerful intelligence for long-running agents and coding".

Updated

The Beta Messages endpoint gained support for BetaRequestToolAdditionBlock and BetaRequestToolRemovalBlock within system message content, enabling mid-conversation tool control, plus the expanded beta header enum.

  • BetaRequestToolAdditionBlock — New system message content block type added; references a declared tool by name to surface it mid-conversation via tool_reference, mcp_tool_reference, or mcp_toolset_reference.
  • BetaRequestToolRemovalBlock — New system message content block type added to hide a previously surfaced tool mid-conversation.
  • system content type union — Changed from array of BetaTextBlockParam to array of BetaTextBlockParam or BetaRequestToolAdditionBlock or BetaRequestToolRemovalBlock.
